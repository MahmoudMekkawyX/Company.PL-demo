# Company.PL demo

Demo build of [Company.PL](https://github.com/MahmoudMekkawyX/Company.PL), an ASP.NET Core MVC app (PL / BLL / DAL layers, repository + unit of work, DTOs, AutoMapper, EF Core, ASP.NET Core Identity).

Differences from the original: SQLite instead of SQL Server so it runs on free hosting, and fictional seed data created on startup. The database resets on every redeploy. Application code is otherwise unchanged. Demo login: demo@example.com / Demo@123.
